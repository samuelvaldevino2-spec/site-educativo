一

As três linhas que você precisa conhecer

Antes de montar qualquer figura, precisamos entender como as linhas se comportam umas com as outras.

  • Paralelas: nunca se encontram, por mais que se estiquem. Sempre com a mesma distância entre si. Ex.: trilhos de trem.
  • Perpendiculares: cruzam-se formando um ângulo de 90°. Ex.: a quina de uma folha.
  • Concorrentes: cruzam-se em um único ponto, mas não necessariamente em 90°.
Importante: toda linha perpendicular é concorrente, mas nem toda concorrente é perpendicular.

二

Como nasce um polígono

Quando você une três ou mais segmentos de reta formando uma linha fechada, cria um polígono. Seus elementos:

  • Lados: os traços que formam o contorno.
  • Vértices: os cantos, onde dois lados se encontram.
  • Ângulos internos: as aberturas entre dois lados dentro da figura.

三

O que é um ângulo?

Definição: ângulo é a abertura entre duas semirretas que partem de um mesmo ponto (o vértice).

Pense numa tesoura: a distância entre as lâminas forma o ângulo. Quando a tesoura está fechada, o ângulo é zero. Quando abre, o ângulo cresce.

TipoMedidaExemplo prático
AgudoMenor que 90°A ponta de um lápis bem afiado
RetoExatamente 90°O canto de uma folha de papel
ObtusoEntre 90° e 180°Um livro semiaberto
Lei imutável: a soma dos ângulos internos de qualquer triângulo é sempre 180°. A de qualquer quadrilátero é sempre 360°. Como a gravidade.

四

Quadrado e Retângulo: irmãos, mas não gêmeos

Retângulo: quatro lados, opostos paralelos e iguais. Todos os ângulos retos (90°).

Quadrado: também tem quatro ângulos retos, mas com um adicional — todos os quatro lados são iguais.

Todo quadrado é um retângulo, mas nem todo retângulo é um quadrado. É como dizer que todo gato é um felino, mas nem todo felino é um gato.

六

Perímetro — a medida da cerca

O perímetro é o comprimento total do contorno de uma figura. Pense como a quantidade de cerca para rodear um terreno.

  • Retângulo (base b, altura h): P = 2(b + h)
  • Quadrado (lado L): P = 4L
  • Triângulo (lados a, b, c): P = a + b + c
Cercando o Terreno

Ajuste os lados e veja a cerca (perímetro) sendo calculada em tempo real.

P = 2(200 + 120) = 640
七

Área — a medida do chão

A área é a medida da superfície interna — quantos quadradinhos cabem dentro da figura. Pense como a quantidade de piso para cobrir uma sala.

  • Retângulo: A = b × h
  • Quadrado: A = L²
  • Paralelogramo: A = b × h (a altura é perpendicular — não o lado inclinado!)
  • Losango: A = (D × d) / 2
  • Triângulo: A = (b × h) / 2 (metade do retângulo de mesma base e altura)
Preenchendo o Chão

Ajuste a base e a altura. Veja quantos quadradinhos (unidades de área) cabem dentro.

A = 6 × 4 = 24 quadradinhos
Cada quadradinho = 1 unidade de área

🌿 Perceba como tudo se encaixa: as linhas formam ângulos, os ângulos definem as formas, as formas ganham nomes, e para cada nome temos um jeito de calcular o perímetro (a cerca) e a área (o chão).

Não decore as fórmulas. Entenda a lógica. Com essa base, você nunca mais vai se confundir.
